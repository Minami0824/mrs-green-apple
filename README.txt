My Mrs. GREEN APPLE — personal PWA

このフォルダは、自分専用のiPhone向けPWAの第2段階プロトタイプです。

入っているもの
- ホーム画面
- LINE風の下部タブ：ホーム / 予定 / グッズ / お金 / 音楽 / ライブ
- 予定・グッズ・支出・ライブの追加
- localStorageによる端末内保存
- セットリストから「ライブで聴いた曲」を自動集計
- iPhoneホーム画面用のPWA manifest / service worker
- オリジナルの簡易アプリアイコン

注意
- このままHTMLファイルを開くだけでは、iPhoneの「ホーム画面に追加」できない場合があります。
- HTTPSで公開されたWebサイトとして置く必要があります。
- Apple Musicの実データ連携、バックグラウンド通知、AIの本格連携は次段階です。
- 個人データは現段階ではブラウザのlocalStorageに保存します。
